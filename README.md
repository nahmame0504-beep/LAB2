# Lab 2 — Représentations Vectorielles (BoW, TF-IDF et Embeddings)

Ce laboratoire explore les différentes méthodes de vectorisation de texte et d'analyse sémantique en NLP, allant des approches fréquentielles classiques aux espaces de plongement (embeddings) pré-entraînés.

---

## Structure du Projet

```text
├── data/
│   └── reviews.txt            # Corpus de textes d'entrée
├── chap2_vectorization.py     # Script Python principal (Tâches & Extensions)
├── bow_frequencies.png        # Graphique des fréquences Bag-of-Words
├── tfidf_heatmap.png          # Carte thermique des poids TF-IDF
├── pca_embeddings_2d.png      # Projection PCA 2D des mots
├── tsne_embeddings.png       # Visualisation t-SNE du vocabulaire étendu
└── README.md                  # Documentation du projet
```
